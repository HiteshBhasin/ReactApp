## Featured Projects

**AI Agent Execution Framework (AEF)**
A framework for running and coordinating multiple AI agents. It uses a durable PostgreSQL work queue (`SELECT ... FOR UPDATE SKIP LOCKED`) so workers can claim jobs safely and tasks survive crashes, along with multi-agent spawning, a PostgreSQL vector store, and LLM API integration. Python backend with a typed Next.js/TypeScript frontend.
*Python · FastAPI · Next.js · TypeScript · PostgreSQL*

**Unified Operations and Intelligence Platform (NestHost)**
My senior capstone project: a property-management platform built as FastAPI microservices, with Gmail IMAP integration, Redis caching, Docker and a CI/CD pipeline. I worked on testing, code review, production troubleshooting and the technical documentation.
*Python · FastAPI · PostgreSQL · Redis · Docker*

**Wildfire and Emergency Navigation Portal**
A solo full-stack app that pulls emergency and navigation data from four external APIs into a single view. [Live demo](https://disasterapp-4wmr.onrender.com)
*React · TypeScript · FastAPI · AWS*
